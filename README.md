# Renegade Noir — Homepage Design Study

Approval-ready desktop and mobile homepage concept for **Renegade Records**, with **Renegade Music Productions** presented as its production division.

This repository contains the owner's requested direction only. The independent creative concept is maintained separately in [Renegade-Records](https://github.com/ahmad012-ui/Renegade-Records).

## Preview

Open index.html through a static development server. The page includes a Desktop / Mobile switch that changes the preview frame and reflows the homepage itself at a 390px mobile viewport.

No build step or package installation is required:

    python -m http.server 8000

Then open http://localhost:8000.

## Owner brief translated into the concept

- Visual direction: 70% luxury / 30% underground, dark cinematic minimalism.
- Palette: Obsidian #0B0B0D, Charcoal #202024, Crimson #C1122F, Ivory #F2F0EB, Steel Grey #85858B.
- Typography: Space Grotesk display, Inter body.
- Main message: “WE DON'T FOLLOW THE SOUND. WE CREATE IT.”
- Navigation: Home, About, Services, Our Work, The Studio, Contact.
- Division relationship: Renegade Music Productions is shown as the production division of Renegade Records.
- No automatic audio playback.

## Files

- index.html — approval board, desktop/mobile toggle and homepage mockup.
- styles.css — visual system, homepage layout and responsive container-query layout.
- script.js — device preview switching, mobile navigation and mockup form state.
- favicon.svg — Renegade Noir monogram.

## Approval mockup limitations / before production

1. The image cards currently use publicly visible Instagram CDN preview images. These are temporary signed URLs and may expire; replace them with approved, downloaded high-resolution Renegade assets in the repository before launch.
2. The hero/studio presentation should ultimately use an approved wide studio photograph or muted studio video supplied by Renegade. The current visuals are real social-post/release references, not a claim that they depict the recording room.
3. Confirm the official WhatsApp number, booking email, studio address, and opening/booking details. None are invented here.
4. The inquiry form is visual-only. It intentionally does not send or store submitted information.
5. Add official audio embeds or streaming links only after the label supplies the approved releases and destinations. There is no autoplay.
6. Confirm the final division naming, exact service wording and all production credits with the owner.

## Production direction after approval

Once the owner approves the homepage direction, replace expiring image previews with studio-supplied assets, connect the inquiry destinations, add confirmed audio players and expand the approved structure into the full site.
